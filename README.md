# 🤖 AI-Meeting Summarizer Bot: Telegram-секретарь для оцифровки планерок

Интеллектуальный Telegram-бот для автоматического протоколирования, расшифровки (Speech-to-Text) и создания саммари рабочих совещаний, планерок и голосовых заметок.

## 💼 Какую бизнес-задачу решает проект?
Руководители компаний, проджект-менеджеры и предприниматели тратят часы на переслушивание голосовых сообщений от сотрудников или записей созвонов, чтобы выписать задачи в Trello/Битрикс24.
Этот бот полностью автоматизирует процесс: менеджер пересылает аудио в бот, скрипт мгновенно конвертирует его, распознает русскую речь и выдает готовый текстовый протокол встречи.

## 🔥 Ключевые возможности:
* **Асинхронный Speech-to-Text:** Быстрая обработка голосовых сообщений любого объема на базе стабильного асинхронного движка.
* **Автоматическая конвертация:** Встроенный транскодер с легкостью преобразует сжатый формат Telegram (`.ogg`) в формат высокой четкости (`.wav`) без потери качества звука.
* **Бизнес-ориентированность:** Бот мгновенно переводит устную речь сотрудников в текстовые поручения, готовые к копированию в таск-менеджеры.

## 🛠️ Технологический стек:
* Python 3.10+
* `aiogram 3.x` (Актуальный асинхронный фреймворк для Telegram Bot API)
* `SpeechRecognition` (Интеграция систем распознавания речи)
* `Pydub` (Высокоскоростная обработка и конвертация аудиопотоков)

## 🚀 Инструкция по быстрому запуску:
1. Установите в систему утилиту `ffmpeg` (необходима для работы с аудиокодеками).
2. Установите Python-библиотеки: `pip install aiogram SpeechRecognition pydub`
3. Укажите ваш `BOT_TOKEN` в файле `main.py`.
4. Запустите бота командой: `python main.py`
